# Soroban Trainer Pro

A structured daily abacus (soroban) training program that runs entirely in your browser. No installation, no accounts, no internet required after download.

## What It Does

Each session flows through 4 timed phases automatically:

1. **Warmup** - Standard addition/subtraction drills. Work problems on your physical abacus and type the answer.
2. **Bead Reading** - See soroban bead positions and identify the number they represent.
3. **Anzan (Mental Math)** - Numbers flash one at a time. Add them in your head. Difficulty adapts to your performance.
4. **Complements** - Quick-fire complement practice. Friends of 10, then Friends of 5.

Sessions are 20, 30, or 40 minutes. Time splits evenly across all 4 phases with smooth transitions between them.

## Features

- Self-contained single HTML file - works offline, nothing to install
- Tracks daily streak and accuracy across sessions
- Adaptive difficulty in Anzan (starts easy, levels up as you improve)
- Sound effects with toggle
- Visual bead rod displays for number visualization
- Session summary with per-phase breakdown
- Works on Windows, Mac, and Linux in any modern browser

## How to Use

1. Download the file
2. Double-click to open (it opens in your default browser)
3. Click "Start Structured Session" and train

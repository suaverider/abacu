SOROBAN TRAINER PRO - HOW TO LAUNCH
===================================

This trainer is a single web-page program. There is nothing to install
and no command to type - it just opens in your web browser.

WHAT YOU SHOULD HAVE (keep all of these in ONE folder):
  - soroban-trainer.html      (the actual program)
  - launch_app.bat            (double-click this to open the program)
  - Create Desktop Shortcut.bat (optional: makes a Desktop icon)
  - README-LAUNCHER.txt       (this file)

EASIEST WAY TO RUN IT
---------------------
1. Put all the files above into one folder, for example:
   C:\Users\<you>\Documents\Soroban Trainer
2. Double-click  launch_app.bat
   The trainer opens in your default browser. That's it.

MAKE A DESKTOP ICON (optional, recommended)
-------------------------------------------
Option A - automatic:
   Double-click  "Create Desktop Shortcut.bat"  one time.
   A "Soroban Trainer" icon appears on your Desktop. Use it from now on.

Option B - manual:
   Right-click  launch_app.bat  ->  "Send to"  ->  "Desktop (create shortcut)".
   (You can rename the desktop shortcut to anything you like.)

NOTES
-----
- If Windows ever asks how to open the .html file, choose Chrome or Edge.
- Your progress saves automatically in that browser. Keep opening it from
  the same folder with the same browser so your saved progress stays.
- Use the in-app "Export Backup" button now and then to save a backup file.
